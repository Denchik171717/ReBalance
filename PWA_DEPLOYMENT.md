## 🚀 Вариант 1: Быстрый Deploy (Vercel) - РЕКОМЕНДУЕТСЯ

### Шаг 1: Подготовка проекта

1. **Инициализируйте Git** (если еще не сделали):
```bash
git init
git add .
git commit -m "Initial commit - PWA ready"
```

2. **Создайте репозиторий на GitHub**:
   - Перейдите на https://github.com/new
   - Создайте новый репозиторий
   - Следуйте инструкциям для push существующего кода

### Шаг 2: Deploy на Vercel

1. **Перейдите на https://vercel.com**
2. **Sign Up/Login** через GitHub
3. **New Project → Import Git Repository**
4. **Выберите ваш репозиторий**
5. **Настройки сборки** (автоматически определятся):
   - Framework Preset: `Other`
   - Build Command: `npm run build`
   - Output Directory: `build/client`
6. **Deploy!**

**Время развертывания: ~2 минуты**

### Шаг 3: Тестирование на Android

1. **Откройте развернутый URL** в Chrome на Android
2. **Появится баннер** "Установить приложение"
3. **Нажмите "Установить"** или через меню браузера: `☰ → Add to Home Screen`
4. **Готово!** Приложение появится на рабочем столе

## 📲 Как установить PWA на Android

### Метод 1: Через баннер установки
- Откройте сайт в Chrome
- Подождите 30 секунд
- Появится автоматический баннер "Установить приложение"

### Метод 2: Вручную
1. Откройте сайт в Chrome
2. Нажмите `☰` (меню) → `Add to Home Screen`
3. Подтвердите установку
4. Иконка появится на главном экране

### Метод 3: Через ярлыки
После установки долгое нажатие на иконку покажет:
- 🧪 **Пройти тест** → прямой переход к оценке
- 📊 **Мой прогресс** → статистика

## 🧪 Локальное тестирование PWA

### Тестирование на компьютере:

```bash
npm run build
npm run start
```

Откройте: http://localhost:3000

**Chrome DevTools:**
1. `F12` → вкладка `Application`
2. Проверьте:
   - **Manifest** - корректность данных
   - **Service Workers** - статус активации
   - **Storage** - кэш файлов

### Тестирование на телефоне (локально):

1. **Найдите IP компьютера:**
   - Windows: `ipconfig`
   - Mac/Linux: `ifconfig`

2. **Запустите с доступом из сети:**
```bash
npm run dev -- --host
```

3. **Откройте на телефоне:** `http://YOUR_IP:3000`

## 🔧 Настройка (опционально)

### Изменить название приложения:

Отредактируйте `public/manifest.json`:

```json
{
  "name": "Ваше Название",
  "short_name": "Краткое",
  "description": "Описание приложения"
}
```

### Изменить цветовую схему:

В `app/root.tsx` измените:

```tsx
<meta name="theme-color" content="#ВАШ_ЦВЕТ" />
```

И в `manifest.json`:

```json
{
  "theme_color": "#ВАШ_ЦВЕТ"
}
```

## 🐛 Troubleshooting

### Service Worker не регистрируется:
- ✅ Убедитесь, что используете **HTTPS** (или localhost)
- ✅ Проверьте в DevTools → Application → Service Workers

### Баннер установки не появляется:
- ✅ Подождите 30+ секунд на странице
- ✅ Взаимодействуйте с приложением (клики)
- ✅ Проверьте, что приложение **не установлено**

### Не работает офлайн:
- ✅ Убедитесь, что Service Worker активен
- ✅ Проверьте кэш в DevTools → Application → Cache Storage
- ✅ Пересоберите: `npm run build`
